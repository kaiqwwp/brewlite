# BrewLite 1.0.0 – Assignment 1

Phiên bản nộp Assignment 1: đặt và thanh toán đồ uống không tiền mặt.

- Menu, chi tiết, size/topping, giỏ hàng, đăng ký/đăng nhập JWT, tạo đơn, thanh toán Ví/Thẻ mô phỏng, xác nhận và lịch sử đơn.
- Task 10: state machine đơn hàng, thanh toán idempotent, tồn kho đồng thời (optimistic lock), mã giảm giá, điểm thưởng.
- 34 test tự động, 55 kịch bản kiểm thử giao diện; sửa 6 lỗi nghiệp vụ (F04, D11, D12, E06, C07, G07).
- Docker Compose chạy web + API + PostgreSQL.
