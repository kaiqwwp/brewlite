# BrewLite 2.0.0 – Assignment 2: từ yêu cầu đến triển khai

## Điểm mới
- **Tài liệu**: SRS (FR/NFR, MoSCoW, tiêu chí chấp nhận), đặc tả UC-05, activity/sequence/class/deployment diagram (PlantUML + SVG), kiến trúc C4 + 7 ADR, ma trận truy vết.
- **Cấu trúc repo**: `apps/web`, `apps/api`, `docs`, `tests/e2e`, `.github/workflows`.
- **CSDL**: migration TypeORM thay `synchronize` (`InitialSchema`, `AddRelationsAndChecks`), khoá ngoại, `CHECK stock >= 0`, `CHECK loyaltyPoints >= 0`; bảng `coupons` đổi thành `promotions`; bảng mới `loyalty_transactions`.
- **API**: `GET /loyalty/me`; `GET /health` kiểm tra CSDL, số migration, phiên bản; log JSON mỗi request; kiểm tra biến môi trường production khi khởi động; container chạy user không phải root.
- **Web**: PWA (manifest, icon, service worker, trang ngoại tuyến); `GET /health`.
- **Chất lượng**: ESLint cho hai app; Vitest + Testing Library (7 test); 4 integration test và 4 unit test mới; E2E Playwright menu → xác nhận đơn.
- **CI/CD**: CI trên PR (install, lint, unit test, build, integration, e2e, gitleaks); CD build image tag commit SHA/semver → GHCR → Render → smoke test → tự rollback; `render.yaml`.

## Thay đổi cần chú ý khi nâng cấp từ 1.0.0
- Thư mục `backend/` → `apps/api/`, `frontend/` → `apps/web/`; dịch vụ compose `backend`/`frontend` → `api`/`web`.
- Biến `DB_SYNC` bị bỏ; schema do migration quản lý (`DB_MIGRATE=false` để tắt chạy tự động).
- CSDL tạo bởi 1.0.0 (synchronize) nên tạo lại: `docker compose down -v && docker compose up --build`.
