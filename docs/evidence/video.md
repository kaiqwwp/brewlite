# Video demo BrewLite 2.0.0

Video demo end-to-end trên bản production (https://brewlite-web-ed96.onrender.com):

**Link video:** DÁN_LINK_VIDEO_VÀO_ĐÂY

Nội dung (khoảng 4 phút):
1. Mở Menu trên khung điện thoại, xem chi tiết đồ uống, chọn size và topping.
2. Thêm vào giỏ, chỉnh số lượng.
3. Đăng ký, đăng nhập.
4. Thanh toán bật "Mô phỏng thanh toán lỗi" → đơn `PAYMENT_FAILED` → thử lại → `PAID`.
5. Trang xác nhận đơn, lịch sử đơn, điểm thưởng.
6. Nhân viên chuyển trạng thái `PREPARING` → `READY` → `COMPLETED`, trang của khách tự cập nhật.
7. `/health` của API hiển thị phiên bản (SHA) đang chạy.
